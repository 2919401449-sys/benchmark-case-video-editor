# 剪映 11.4.2 / 11.5.0 草稿适配

## 目标

把 `edit_plan.json` 转成一个独立、可继续编辑的剪映草稿。适配器只创建新草稿，不覆盖任何已有草稿，也不自动点击“导出”。经过验证的 `pyJianYingDraft` 已随 Skill 放在 `vendor/` 中；默认不依赖本机其他目录。`--repo` 仅用于维护者显式测试另一版本。

## 两阶段验证

1. `plain` 模式先在工作目录生成明文测试包，用于检查轨道、片段数量、素材路径和时间码。
2. `encrypted` 模式调用本机剪映安装目录中的 `videoeditor.dll` 写入剪映使用的私有格式，再由剪映 11.4.2 实机打开检查。

剪映自动升级后，旧版本目录可能仍然存在但已经不包含 `videoeditor.dll`。导出前应确认当前版本目录中确实存在该文件；当前结构测试覆盖 11.4.2 和 11.5.0，最终仍以剪映实际打开结果为准。

不能跳过第一阶段。剪映草稿格式不是公开标准，即使文件成功生成，也不代表当前剪映版本一定接受。

当前加密草稿导出依赖 Windows 剪映的 `videoeditor.dll`，只在 Windows 剪映专业版 11.4.2 / 11.5.0 验证。macOS 可以运行上游转写、剪辑计划、B-roll、字幕和图表流程，但暂不生成 Mac 版剪映草稿。

## 草稿内容

- `A-roll 主轨`：保留口播原声，按 `source_in/source_out` 截取并连续排列。
- `B-roll 覆盖`：覆盖在 A-roll 上方，默认静音，避免现场杂音盖住口播。
- `信息图表`：透明 PNG 或 ProRes 4444 MOV 覆盖层，默认静音；动态图表的面板、数值、步骤、圆环可分层，位置和透明度关键帧可继续修改，图中文字需重新生成。动态图表导出使用 `media_inventory_with_charts.json` 登记 MOV 的尺寸和时长。
- `中文字幕`：把每段长讲稿按标点和长度拆成较短字幕，并按字数比例分配显示时间。
- 字幕显示文本不保留标点；逗号、句号、问号等口语停顿统一替换为空格。SRT 时间码中的逗号不属于字幕显示文本。
- 字幕使用白字、黑色描边（`TextBorder width=20`），字号固定为 4.0，相对于旧版导入默认 5.0 缩小 20%；每次重新生成不再累计缩小。字幕依然是可编辑的剪映文字轨。
- 默认位置下移到 `transform_y=-0.88`。存在 `caption_segments` 时按已审核语音锚点导入，不使用字数比例重新计时；原字幕路径仅供旧项目兼容。先运行 `editorial_quality.py audit` 通过真实性和签名检查。
- 图表背景模糊使用独立静音视频轨，位于全部图表、Logo 和字幕下方；层级分组后再按时间分轨，避免模糊盖住前景。原始 A/B-roll 与音轨保留不变。

## 运行示例

```powershell
python scripts/export_jianying.py `
  --edit-plan "E:\work\edit_plan_with_charts.json" `
  --inventory "E:\work\media_inventory.json" `
  --draft-root "E:\work\jianying-test\Drafts" `
  --artifacts-dir "E:\work\jianying-test\artifacts" `
  --draft-name "案例自动剪辑测试_v1" `
  --mode plain
```

通过明文结构检查后，才允许在已经确认的剪映草稿目录中使用 `encrypted` 模式。实际写入前必须关闭正在编辑该草稿的剪映窗口，并使用一个从未存在过的新草稿名。

## 验收清单

- 剪映首页能看到测试草稿；
- 打开草稿无“文件损坏”提示；
- A-roll 画面和声音连续，切点与审核计划一致；
- B-roll 位于上层且没有杂音；
- 信息图表位于 B-roll 上方，透明区域能看到下层画面，出现时间与对应口播一致；
- 中文字幕可单独编辑；
- 素材没有离线；
- 总时长、分辨率和帧率与 `edit_plan.json` 一致。

如果实机检查失败，不修改源素材，也不覆盖现有草稿。交付 `edit_plan.json`、预览视频和导出报告，以便修订适配器。
